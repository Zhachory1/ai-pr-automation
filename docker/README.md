# Local fleet containers

`docker-compose.yml` runs Hindsight and its Postgres DB, Coderag, nginx, and direct PR review/maintenance cron producers. Hermes itself runs as the current user's `~/.hermes` gateway. Compose discovers PRs and sends them to the authenticated host Kanban ingress at `host.docker.internal:8767`; that process uses the local Hermes CLI to create tasks. There is no fleet request queue, controller, or status server in the default runtime.

From the repo root, configure `.env` (or set `COMPOSE_ENV_FILES` to the operator env file). `scripts/fleet.sh support-up` starts only Hindsight, Coderag, and the proxy; it does not start cron producers or modify the personal Hermes gateway. After starting the host ingress and placing a read-only GitHub discovery token and two per-kind ingress keys in owner-only files listed in `.env.example`, `scripts/fleet.sh up` also starts both direct PR crons. This is live PR discovery and can trigger model and GitHub effects; do not use it as a health check.

Use `scripts/fleet.sh status` and `scripts/fleet.sh logs` for inspection. `scripts/fleet.sh down` stops Compose services, **not** the personal Hermes gateway; it does not delete volumes. Never use `docker compose down -v`. Historical request data is archived offline, including unresolved `reconcile` records. Do not replay them without checking external effects.

The Compose nginx proxy publishes only loopback ports: HTTP on `127.0.0.1:80` for port-free `*.localhost` aliases, plus the existing HTTPS `127.0.0.1:8080`. `hermes.localhost` reaches the authenticated API, `dashboard.localhost` the Kanban dashboard, `memory.localhost` Hindsight UI, `memory-api.localhost` Hindsight API, and `code.localhost` Coderag. Unknown port-80 hosts are rejected; retired `localhost/signal/` returns 410. Signal uses the current user's `ai.hermes.signal` LaunchAgent and `~/.local/share/signal-cli`. The unused Docker Signal service starts only if explicitly targeted or the `legacy-signal` profile is enabled; its `signal_state` volume is retained for rollback.

Hindsight's `hindsight_pgdata` must remain on `pgvector/pgvector:pg18` at `/var/lib/postgresql/18/docker`. Changing either the major version or mount path without a migration can silently initialize an empty database. `hindsight-bank-init` sets the shared bank's read-only MCP tools when the full runtime starts; `support-up` does not rerun it. The host Hermes profiles use the recall-only shim on `127.0.0.1:8888` and Coderag MCP on `127.0.0.1:9750`. A live recall may use a model; tool discovery alone does not.
