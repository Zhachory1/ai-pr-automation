# Local fleet containers

`docker-compose.yml` runs Hindsight and its Postgres DB, Coderag, Signal, the HTTPS proxy, and direct PR review/maintenance cron producers. Hermes itself runs as the current user's `~/.hermes` gateway; Compose reaches its Runs API at `host.docker.internal:8642`. There is no fleet request queue, controller, or status server in the default runtime.

From the repo root, configure `.env` (or set `COMPOSE_ENV_FILES` to the operator env file). `scripts/fleet.sh support-up` starts only Hindsight, Coderag, Signal, and the proxy; it does not start cron producers or modify the personal Hermes gateway. After placing a read-only GitHub discovery token and the two profile API keys in owner-only files listed in `.env.example`, `scripts/fleet.sh up` also starts both direct PR crons. This is live PR discovery and can trigger model and GitHub effects; do not use it as a health check.

Use `scripts/fleet.sh status` and `scripts/fleet.sh logs` for inspection. `scripts/fleet.sh down` stops Compose services, **not** the personal Hermes gateway; it does not delete volumes. Never use `docker compose down -v`. The old `requests_pgdata` volume contains unresolved historical requests and remains declared but unused. Do not requeue or discard them during this cutover.

The proxy publishes only `127.0.0.1:8080` over HTTPS: `hermes.localhost` routes to the authenticated Runs API (health at `/health`, no dashboard), `memory.localhost` to Hindsight, `code.localhost` to Coderag, and `localhost/signal/` to the Signal REST API. Signal's state stays in the `signal_state` volume; no message is sent by startup. The Signal REST endpoint is not the old host notifier's `/api/v1/check` protocol.

Hindsight's `hindsight_pgdata` must remain on `pgvector/pgvector:pg18` at `/var/lib/postgresql/18/docker`. Changing either the major version or mount path without a migration can silently initialize an empty database. `hindsight-bank-init` sets the shared bank's read-only MCP tools when the full runtime starts; `support-up` does not rerun it. The host Hermes profiles use the recall-only shim on `127.0.0.1:8888` and Coderag MCP on `127.0.0.1:9750`. A live recall may use a model; tool discovery alone does not.
