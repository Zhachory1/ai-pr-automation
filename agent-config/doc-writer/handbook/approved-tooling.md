# Approved Tooling, Languages, and MCPs

> **Source**: go/dev-handbook
> **Related files**: [standards-paved-road.md](standards-paved-road.md) (paved road philosophy), [quick-reference.md](quick-reference.md) (resource links), [testing-standards.md](testing-standards.md) (testing frameworks and best practices)

The approved list of agentic and AI-enabled tools is reviewed regularly. Builders are encouraged to propose new tools and share usage learnings so that the paved road evolves with the needs of the organization.

## Languages (with testing frameworks)

* Java (junit)
* C# (xunit)
* JavaScript/TypeScript (jest)
* Python (pytest)
* Go (testing)

## IDEs and Agentic Development Systems

* VS Code + Copilot
* Cursor
* JetBrains + Junie
* Replit (for POCs)
* N8N

## Work Tracking

* Notion (top-level bets)
* Jira (work items and tasks)

## Source Control

* GitHub Enterprise (Rokt or mparticle-by-rokt orgs)

## MCPs (Model Context Protocols)

Model Context Protocols provide AI agents with specialized knowledge and capabilities:

* **Jira**: Work tracking and task management integration
* **AI Code Gurus**: Specialized knowledge for mP/Rokt Brain/Aftersell/etc codebases
* **RoktGPT**: General Rokt platform knowledge
* **Datahub**: Data catalog and lineage information
